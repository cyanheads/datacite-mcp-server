# 0.2.1 — 2026-10-31

## Changed

- **Search counts** serve up to 1,000 works or repositories per page; larger positive integer counts clamp with requested/applied notices, logs, and a counter. Graph counts retain a 100-node cap. Set `DATACITE_CLAMP_LIMITS=false` to advertise and enforce strict caps. ([#33](https://github.com/cyanheads/datacite-mcp-server/issues/33))

## Fixed

- **Scientific text** decodes all semicolon-terminated WHATWG named references once in titles, snippets, rendered descriptions, and text citations. ([#20](https://github.com/cyanheads/datacite-mcp-server/issues/20))
- **Affiliation countries** normalize `UK` to `GB` with a notice and reject never-assigned codes before searching; current and historical ISO alpha-2 codes plus `XK` remain accepted. ([#32](https://github.com/cyanheads/datacite-mcp-server/issues/32))
- **JATS exports** disclose empty names and inconsistent years while preserving upstream bytes, including warnings accompanying complete-document download URLs. ([#35](https://github.com/cyanheads/datacite-mcp-server/issues/35))

## Dependencies

- `entities` ^9.0.0 added for WHATWG named-character decoding.
- `@biomejs/biome` 2.6.3 → 2.6.4.
- `@types/node` 26.6.5 → 26.6.6.
