# 0.2.0 — 2026-10-26

## Added

- Publish datacite-guide as an MCP skill resource for identity resolution and research-output evidence checks.
- **Repository search provenance** includes the composed `effectiveQuery` on both response surfaces, including empty pages; ID lookups retain their explicit ID echo. ([#30](https://github.com/cyanheads/datacite-mcp-server/issues/30))

## Changed

- **Oversized machine exports** omit `citation` above 100,000 UTF-16 code units and return the exact negotiated `downloadUrl` and `totalCharacters`, with `shown: 0` and retrieval guidance. Consumers must fetch the URL instead of importing a partial document. ([#27](https://github.com/cyanheads/datacite-mcp-server/issues/27))
- **Desktop packaging** excludes development files and dependency build output while retaining executable SDK skill modules; root Agent Plugins manifests and packaging validation are synchronized. ([mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794))
- **Development guidance** and setup examples follow the adopted framework's rendering, configuration, Skills, and packaging contracts.

## Fixed

- **Geographic polygons** retain deposited vertex order, closing vertices, and optional interior points through normal and selected-list responses; malformed polygons disclose omission without dropping valid sibling geometry. ([#26](https://github.com/cyanheads/datacite-mcp-server/issues/26))
- **Literal searches** reject nonblank text whose escaped clause is empty before contacting DataCite, preventing accidental unfiltered searches. ([#28](https://github.com/cyanheads/datacite-mcp-server/issues/28))
- **Description rendering** preserves paragraphs, lists, preformatted text, and table boundaries while keeping filename patterns and other deposited Markdown literal; links remain links and complete machine payloads retain their whitespace. ([#29](https://github.com/cyanheads/datacite-mcp-server/issues/29))
