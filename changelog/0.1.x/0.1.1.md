# 0.1.1 — 2026-09-26

First published release: six read-only tools over the public DataCite REST API and `doi.org/ra`, keyless, over stdio or Streamable HTTP. No resources or prompts.

## Added

- **`datacite_search_works`** — search DOI metadata by `text` (reserved characters escaped) or `query` (OpenSearch syntax), filtered by `resource_types`, `creator`, `affiliation`, `affiliation_country`, `funder` (+ `include_child_funders`), `subject`, `fields_of_science`, `repository_ids`, `provider_ids`, `licenses`, `language`, `place`, `published_from`/`published_to`, and `min_citations`. Ranked pages (`sort`, `limit`, `page`) reach the first 10,000 matches; `cursor: "*"` walks the full set in registration order; `include_facets` adds top facet counts.
- **`datacite_get_work`** — the full deposited metadata for one `doi`, with its repository, provider, and DataCite's counts; long lists are capped, with full counts in `truncatedLists`. A DOI DataCite does not hold returns `found: false` naming the registration agency that does.
- **`datacite_trace_relations`** — the relation graph around any DOI, a journal article's included: each edge keeps the asserted `relationType` and names its sources (`metadata`, `reverse_metadata`, `event_data`). Takes `doi`, `depth` (1–2), `relation_types`, `include_event_data` (default true), and `max_nodes` (1–100, default 50); returns at most 1,000 edges and a `coverage` block per source.
- **`datacite_search_repositories`** — find repository accounts by `query`, `field_of_science`, `repository_types`, `certificates`, `software`, `client_type`, or `provider_id`, or look up up to 25 `repository_ids` alone, paged by `limit` and `page`. Returns the `repositoryId` that work search filters on.
- **`datacite_get_citation`** — one `doi` as a formatted citation in a CSL `style` and `locale` (APA in US English by default) or as a machine `format`: `csl_json`, `bibtex`, `ris`, `datacite_json`, `datacite_xml`, `schema_org`, `codemeta`, or `jats`. A style DataCite would silently render as APA fails as `unsupported_style`; a payload over 100,000 characters is cut and flagged.
- **`datacite_list_reference`** — offline decoder for 18 `topic` values: controlled vocabularies, accepted identifier forms, query-syntax field paths, verified citation styles and locales, and coverage and rate-limit rules.
- **`DATACITE_CONTACT_EMAIL`** — contact email sent in the User-Agent as `mailto:` (never a URL parameter), moving requests to DataCite's identified rate tier.
- **`DATACITE_MAX_REQUESTS_PER_5MIN`** — request budget per 5-minute window, 50–1000; default 800 with a contact email, 400 without.
- **Upstream requests** — every DataCite and doi.org request goes through a shared in-process TTL cache and a request pacer; a spent budget fails as `rate_limited` with the wait in seconds. Redirects are not followed, a response over 32 MB is not read, and upstream response bodies never reach the caller.
- **Server instructions and session mode** — `initialize` carries the search → open → cite workflow, the per-DOI citation-count caveat, and the depositor-text trust boundary; HTTP runs `stateless`.
- **Distribution** — npm package `@cyanheads/datacite-mcp-server`, MCP Registry entry, multi-arch GHCR image, Claude Desktop `.mcpb` bundle, and Claude Code and Codex plugin manifests.

## Fixed

Issues filed against pre-release builds:

- **`datacite_search_works`** — `/` in `text` or a creator or funder name, lexical query errors now `invalid_query`, a cursor walk ending on a full page, and ORCID URLs with a trailing slash ([#1](https://github.com/cyanheads/datacite-mcp-server/issues/1), [#2](https://github.com/cyanheads/datacite-mcp-server/issues/2), [#3](https://github.com/cyanheads/datacite-mcp-server/issues/3), [#4](https://github.com/cyanheads/datacite-mcp-server/issues/4)).
- **`datacite_trace_relations`** — second-hop reverse reads disclosed in `coverage`, `relation_types` read from the traced DOI's side, cap, citation-count, and non-DataCite-root notices that name only real causes and next steps, and widely used GBIF datasets whose reverse page was too large ([#5](https://github.com/cyanheads/datacite-mcp-server/issues/5), [#6](https://github.com/cyanheads/datacite-mcp-server/issues/6), [#7](https://github.com/cyanheads/datacite-mcp-server/issues/7), [#8](https://github.com/cyanheads/datacite-mcp-server/issues/8), [#9](https://github.com/cyanheads/datacite-mcp-server/issues/9), [#15](https://github.com/cyanheads/datacite-mcp-server/issues/15)).
- **`datacite_get_citation`** — `tl-PH` and `hy-AM` dropped from the locale list, formats DataCite cannot render now `format_unavailable`, and other-agency guidance names the requested format ([#10](https://github.com/cyanheads/datacite-mcp-server/issues/10), [#11](https://github.com/cyanheads/datacite-mcp-server/issues/11), [#14](https://github.com/cyanheads/datacite-mcp-server/issues/14)).
- **DOI handling** — a DOI whose suffix carries a literal percent-escape is no longer decoded and rejected, and `doiUrl` is percent-encoded ([#12](https://github.com/cyanheads/datacite-mcp-server/issues/12), [#13](https://github.com/cyanheads/datacite-mcp-server/issues/13)).
