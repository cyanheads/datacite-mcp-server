# 0.2.2 — 2026-11-15

## Added

- **`include_child_funders`** accepts a Crossref Funder ID that ROR maps to one organization; a ROR outage reports the new retryable `ror_unavailable`. ([#41](https://github.com/cyanheads/datacite-mcp-server/issues/41))
- **`version_scope`** (`all` / `series` / `releases`) on `datacite_search_works` counts and returns every DOI, one per version series, or only versions. ([#42](https://github.com/cyanheads/datacite-mcp-server/issues/42))
- **`relation_types`** on `datacite_get_work` pages only the `relatedIdentifiers` entries asserting those types, with per-type continuations in `truncatedLists[].byRelationType` and `listPage.relationTypes`. ([#43](https://github.com/cyanheads/datacite-mcp-server/issues/43))

## Changed

- **A 0.2.1 cursor** for a walk filtered by a creator name, a funder name, or a `place` matched as a substring now fails as `invalid_cursor`; restart the walk with `cursor: "*"`.
- **A malformed cursor** is reported as `invalid_cursor` before other input checks.
- **Rate-limit errors** end with `retry after N`, inherited from the framework.
- **Bun floor** `>=1.4.0` → `>=1.4.4`.

## Fixed

- **`creator` and `funder` names** match as a proximity phrase inside one creator or funding reference, so tokens from different people or funders no longer combine. ([#37](https://github.com/cyanheads/datacite-mcp-server/issues/37))
- **`place`** matches inside deposited place names, tried as typed and in four case forms; it falls back to an exact match, with one notice, when a case form is over 250 characters or the request would pass DataCite's URL limit. A `place` of line breaks only is unset. ([#38](https://github.com/cyanheads/datacite-mcp-server/issues/38))
- **`datacite_trace_relations` notices** name the reverse records left unread and the `datacite_search_works` query actually sent, inverse relation types included; the query is left out when it is over 2,000 characters. ([#39](https://github.com/cyanheads/datacite-mcp-server/issues/39))
- **`datacite_get_citation`** pages a long document with `offset`, `limit` (default 100,000 UTF-16 units, at most 1,000,000), and `nextOffset`, instead of cutting text or withholding machine formats past 100,000 units. ([#40](https://github.com/cyanheads/datacite-mcp-server/issues/40))
- **A wildcard term DataCite rejects as too complex** reports `invalid_query` on both search tools.
- **`invalid_cursor` and `page_ceiling` errors** render the start cursor `"*"` as a code span in `content[]`.
- **The response cache** counts retained memory, not UTF-8 length.
- **Negotiated documents and `datacite_get_work` records** are cached up to 10,000,000 bytes, so a slice walk or a long record's list pages fetch once.
- **The relation-type vocabulary** describes `Other` as a DataCite schema 4.7 value.
