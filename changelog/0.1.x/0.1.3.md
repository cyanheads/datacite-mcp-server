# 0.1.3 — 2026-10-18

## Changed

- **Read caps** apply at most 100 to work/repository limits and graph nodes, with requested/applied notices; repository lookups query the first 25 distinct normalized IDs and name omitted IDs. Filter-array bounds remain strict. ([#21](https://github.com/cyanheads/datacite-mcp-server/issues/21))
- **Record lists** support `list`/`offset` continuation over valid mapped entries, with explicit paging metadata and exact continuation recipes for every default truncation. ([#22](https://github.com/cyanheads/datacite-mcp-server/issues/22))
- **Event Data** supports `event_offset` continuation without metadata consuming the node cap; coverage distinguishes exhaustion, blocked classification, unavailable reads and the 10,000-result ceiling. Unknown upstream totals are omitted. ([#23](https://github.com/cyanheads/datacite-mcp-server/issues/23))
- **Development guidance** syncs framework API references, field testing, packaging, security review and release procedures; README and design documentation describe the bounded reads.

## Fixed

- **FundRef search** resolves exact ROR identities with a bounded lookup and disclosed literal fallback; cursor walks preserve their initial match set across restarts and mapping changes, including previously issued cursors. ([#19](https://github.com/cyanheads/datacite-mcp-server/issues/19))
- **Deposited text** normalizes titles and snippets once before snippet truncation and escapes remaining angles in Markdown; structured descriptions retain deposited text. ([#20](https://github.com/cyanheads/datacite-mcp-server/issues/20))
- **Reverse relations** include `relatedItems`, verify target/type pairs and deduplicate both assertion lists at both depths while counting their combined size against the reverse-read bound. ([#17](https://github.com/cyanheads/datacite-mcp-server/issues/17))
- **Search guidance** distinguishes ranked-ceiling stops from exhaustion, gives blank facets their IDs, accepts spaced license IDs verbatim after trimming/lowercasing, and documents deposition timestamp ranges. ([#24](https://github.com/cyanheads/datacite-mcp-server/issues/24))
